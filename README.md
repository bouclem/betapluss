# Beta+

A Minecraft Beta 1.7.3 mod by **sqersters**

🌐 [Website](https://voidwaremods.vercel.app/index.html) | 📦 [GitHub](https://github.com/bouclem)

---

## Requirements

- Prism Launcher (or similar)
- Java 8

## Installation

1. Install [Prism Launcher](https://prismlauncher.org/) (or a similar launcher)
2. Create a new instance with version **b1.7.3** (Beta 1.7.3)
3. Go to the instance settings, then the **Version** tab
   
   ![Version tab](https://github.com/user-attachments/assets/030548d8-1455-41cf-a179-146aa0010b83)

4. Click **Replace Minecraft.jar** or **Add to Minecraft.jar**
5. Select the `betaplus-0.1.0.jar` file
6. Done! Launch and enjoy!
